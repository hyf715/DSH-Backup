哈苏 X2D 错误码 49.3 = "Failed to set lens aperture"（镜头光圈设定失败/光圈叶片驱动异常）：机身向 XCD 镜头发光圈指令后，镜头 MCU 超时未到位或位置反馈与设定不符即触发。刷了对焦加速补丁后更易诱发（提速与收光圈指令时序冲突/丢包）。排查：关加速或还原→擦触点→M档不同光圈复测；恢复出厂后仍必现则可能是镜头光圈电磁模组硬件问题。用户 2026-10-11 换镜头后遇到此报错。
