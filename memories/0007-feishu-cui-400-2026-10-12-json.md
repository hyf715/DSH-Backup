feishu-cui 卡片 400 真实根因（2026-10-12 排查）：不是内容超长也不是 JSON 损坏。真因是 agent 回答 markdown 里带了本地图片路径（如 ![原图](/Users/huangyingfeng/lut-lab/preview-orig.jpg)）。飞书卡片 markdown 的 ![](x) 里 x 必须是 POST /im/v1/images 上传得到的 img_v2_/img_v3_ key，本地路径会让整张卡被拒：code 230099 / ErrCode 200570 "card contains invalid image keys"。插件原本零 img_key 处理，markdownElement 是裸透传。关键教训：日志里 code=undefined 是假象——飞书 4xx 以 axios 抛错回来，业务码躺在 error.response.data 里，原代码只取 error.message 把真码丢了；真实码要去 ~/.dsh/web-restart.log 的多行 [error]: 块里挖。
