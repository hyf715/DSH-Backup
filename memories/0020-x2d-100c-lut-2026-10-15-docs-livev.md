X2D 100C 实时取景 LUT 架构 + 屏幕常亮（2026-10-15 调查，完整记录见仓库 docs/LIVEVIEW-LUT.md）：
【屏幕常亮】息屏根因=/data/config/system.ini 的 screen_idle_timeout=180（3分钟）。运行时解法：`odindb-send -s system -p screen_idle_timeout 86400` 立即生效且自动持久化回写 system.ini（无需重启）。保活 API：`odindb-send -s system -m notify_activity 0 E_ActivityAction_ResetScreenIdleTimer`（枚举 WakeSystem=1/ResetSystemPowerTimer=2/ResetScreenIdleTimer=4）。本机无 `settings` 命令（裁剪了 SettingsProvider）。备份 /data/config/system.ini.bak-keepalive-20261015。
【取景链路】camera-gui(Qt6/QML, Wayland客户端)→weston(Wayland合成器)→显示引擎 e2-lcdc0-dsi(plugins.conf: 3dlut=lcd,0,709)→LCD；GPU=PowerVR Rogue(/dev/dri/renderD128,/dev/ion,/dev/pvr_sync)。camera-gui 的 fd 里无任何 LUT 文件。
【两个 LUT 注入点】A=显示引擎硬件3D LUT（全屏生效含UI，数据在 ISP 固件 /system/etc/iq/ec1706_config.bin，非 copy_3dluts_files）；B=Qt shader LutControl（仅取景，QML ShaderEffect+uselut 标志，但 Constants.backdisplayLut/evfLut 是编译期 C++ 常量，D-Bus 不可运行时设，需 LD_PRELOAD hook CommonConstants::backdisplayLut 激活 uselut=1）。
【copy_3dluts_files】/system/bin/ 下 12288B=16³×3，确为 16×16×16 RGB 3D LUT（非identity校准曲线，R压缩到216），孤儿文件无任何脚本引用。
【原生无胶片风格】E_ColorProfile 仅 SRGB(0)/AdobeRGB(1)（色彩空间非风格），无 E_Look/E_Style/E_Hncs。
【关键技巧】工厂 HblShell(command-65)=root 通道，可读 /system/bin/camera-gui、写 /sys/power/wake_lock；adb shell=su:s0 读不了相机二进制/看不到相机进程。所有特权操作走工厂通道绕开 watch.sh（watch.sh 由"回放链路优化"进程持有）。推荐路线 A2（hook backdisplayLut）。
