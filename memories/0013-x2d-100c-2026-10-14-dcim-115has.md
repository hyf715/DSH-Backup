X2D 100C 相机回放机制（2026-10-14 实锤）：回放相册显示的图**不是**磁盘上 DCIM/115HASBL/B000799x.JPG，而是配套的 B000799x.3FR（RAW）文件**尾部内嵌的预览 JPEG**。证据：cam.log 里 imagestore 请求 `/ssd/115HASBL/B0007993`（无扩展名，storage 服务解析成 .3FR），ImageMemory description 是 `...B0007993.3FR` format Jpeg，尺寸 3888x2918。3FR 是 TIFF 结构（head: II*\x00，IFD0 @ offset 8，小端），预览 JPEG 通过 IFD0 的 tag 273 (StripOffsets) / tag 279 (StripByteCounts) 定位（实测 7992/7993/7994 偏移都是 210530304，长度逐张不同 1236992~1273856）。预览段恰是文件最后一段：210530304 + StripByteCounts == 文件总大小。所以"只 LUT 磁盘 JPG"在相机屏幕上看不到效果，必须补丁 3FR 内嵌预览：提取该段→lut-apply→head -c 头 + cat LUT + truncate 补零到原长 + chown media_rw:media_rw + chmod 770 + mv 原子替换。toybox dd 无 conv=notrunc，seek 写会截断文件（实测），重建法才是安全写回路径。回放缓存：camera-storage 有 Cache（重启进程后日志仍 Exists in cache: true，说明缓存持久化或随新请求重建），texture atlas 在 camera-gui 进程；新照片无缓存，处理完再回放直接显示新图。
